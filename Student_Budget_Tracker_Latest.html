📲 3-Step Setup with MacroDroid (Free on Android Play Store)

1
Install MacroDroid & Add Trigger

Open MacroDroid > Add Macro > Trigger: Notification Received > Select apps: Google Pay, PhonePe, Paytm, CRED, HDFC/SBI/ICICI.

2
Add Action: HTTP Request

Action: HTTP Request > Method: POST > URL: (Paste the Mobile Wi-Fi Webhook above) > Content-Type: application/json.

3
Set Request Body JSON 
{
  "packageName": "[notification_package_name]",
  "appName": "[notification_app_name]",
  "title": "[notification_title]",
  "text": "[notification_text]",
  "postTime": [system_time_ms]
}
